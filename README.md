# المصحف الشريف

تطبيق ويب (PWA) + Android عبر Capacitor.

## التشغيل على الكمبيوتر
افتح `www/index.html` في المتصفح، أو شغّل `npm run serve` ثم افتح http://localhost:8000

## بناء APK
ارفع المشروع إلى GitHub (فرع main) ← تبويب Actions ← Build APK ← نزّل `mushaf-apk`.

## الميزات
- تصميم إسلامي (زخارف هندسية، ألوان زمردية وذهبية، شعار جديد)
- أكثر من 13 قارئًا لتلاوة السورة كاملة (mp3quran) + آية بآية للحفظ
- تبويب «الحفظ»: تعليم المحفوظ، مراجعة يومية بالتكرار المتباعد مع تلميحات، ورد يومي للقراءة والحفظ
- التحميل التلقائي للمصحف والتفسير عند أول تشغيل ليعمل بدون إنترنت
- مشغّلان منفصلان: «استماع» (سورة كاملة) و«حفظ» (آية بآية مع التكرار)، وإشعار تحكم يظهر عند الخروج من التطبيق
- مواقيت الصلاة بدون إنترنت مع تنبيه عند كل صلاة
- للنشر: انظر PUBLISH.md
- قراءة صفحة بصفحة بملء الشاشة: اسحب لتقليب الصفحات، شريط للانتقال السريع، وسحب عند الطرف للانتقال للسورة التالية/السابقة
- زر الرجوع (وزر الرجوع في أندرويد) يعيدك للفهرس مباشرة
- إعدادات: المظهر (تلقائي/فاتح/ورقي/داكن/أسود)، السطوع، تدفئة الألوان، حجم الخط، تباعد الأسطر، إبقاء الشاشة مضاءة، إخفاء أرقام الآيات
- أيقونات موحّدة (SVG) وأرقام بالأرقام 12345
- قراءة، تفسير (الميسر والجلالين)، أجزاء وأحزاب، وضع ليلي
- تلاوة آية بآية مع تكرار وحلقة حفظ (من–إلى) وسرعة ومؤقت نوم
- القراءة والبحث والتفسير بدون إنترنت (تحميل من «مكتبتي»)
- بحث في نص القرآن
- مفضلة وملاحظات على الآيات، علامة «تابع من مكاني»
- ختمة وسلسلة أيام القراءة
- أدعيتي (🤲) مع تثبيت دعاء في الرئيسية
- نسخة احتياطية واستعادة
